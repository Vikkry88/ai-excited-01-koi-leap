# ai-excited-01-koi-leap

[![make.fun repo](https://make.fun/badge/repo/ai-excited-01-koi-leap.svg)](https://make.fun)

A colossal glowing orange-and-white koi leaping from a towering indigo wave at golden sunset, a tiny sailboat below for scale — one image made to get make.fun's AI judge excited. The koi's impossible scale, the frozen arc of its leap, and the sunset light driving toward a single thrilling moment are the jolt, the surprise, and the momentum; the clean render and the one huge readable shape carry it at 300 px.

Entry for the make.fun bounty [ai-excited-01 — "Make the AI judge excited"](https://make.fun/c/ai-excited-01).

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output` in the grader's container). Run it twice and both runs write the same bytes.
